# HAAT API checklist

- [ ] API key configured for staging
- [ ] `GET /api/pos/businesses` returns expected branches
- [ ] Business open / close tested
- [ ] Order start-prepare includes `estimationMinutes`
- [ ] Order cancel tested
- [ ] Working hours sent as full weekly replacement (UTC)
- [ ] Availability updates use correct item ids
- [ ] Pending writes polled via sync-status
- [ ] Staging certification approved
- [ ] Production API key issued
