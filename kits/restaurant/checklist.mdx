# Restaurant checklist

- [ ] Staging auth configured (Bearer or HMAC)
- [ ] `GET /api/menu` returns full menu under 5s
- [ ] Categories include meals and deals
- [ ] Addon groups have `min` / `max`
- [ ] `posId` values are stable
- [ ] Localization includes at least `en`
- [ ] `POST /api/orders` accepts HAAT payload
- [ ] Idempotency key handled
- [ ] Response includes `posOrderId`
- [ ] `401` / `500` handled cleanly
- [ ] Staging certification approved by HAAT Integration
- [ ] Production credentials issued
- [ ] First production order tested
