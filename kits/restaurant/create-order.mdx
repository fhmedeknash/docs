---
title: "Create order in POS"
description: "HAAT sends a new customer order to your POS in real time."
api: "POST https://pos.example.com/api/orders"
---

Reply with your `posOrderId`. The same `Idempotency-Key` must not create a second order.

**Example:**

<pre class="redoc-example"><code>Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
X-Haat-Version: 1.0
Idempotency-Key: 7dda287d-21de-4159-a058-e60618e9b786</code></pre>

## Responses

<details class="redoc-response" open>
  <summary><span class="redoc-code">200</span> Order accepted</summary>
  <div class="redoc-response-body">Return <code>status</code>, <code>message</code>, and <code>posOrderId</code>.</div>
</details>

<details class="redoc-response redoc-response-error">
  <summary><span class="redoc-code">401</span> Invalid or missing authentication token</summary>
  <div class="redoc-response-body">Check Bearer or <code>X-Signature</code>.</div>
</details>

<RequestExample>
```bash cURL
curl -X POST https://pos.example.com/api/orders \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "X-Haat-Version: 1.0" \
  -H "Content-Type: application/json" \
  -d '{"orderId":87452,"businessId":1021,"customer":{"name":"John Cohen","phone":"+972501234567"},"items":[{"id":5012,"quantity":2,"price":32.5}],"payments":[{"paymentType":"credit_card","amount":84.9}],"payRestaurant":84.9,"deliveryType":"delivery"}'
```
</RequestExample>

<ResponseExample>
```json 200
{"status":"success","message":"Order accepted","posOrderId":"ORD-78456"}
```
</ResponseExample>
