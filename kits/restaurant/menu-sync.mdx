# Menu sync

HAAT calls your POS to build or refresh the restaurant menu.

## Endpoint

`GET /api/menu`

Full field contract: [Get menu from POS](/kits/restaurant/get-menu).

## Rules

- Keep `PosId` values **stable**
- `en-US` is required on every `Name`
- Return **categories**; each category has `Meals` and `Deals`
- Meal modifiers use `Groups` → `MealContents`
- Deal choices use `MealGroups` → `Meals`

## When HAAT syncs

- Initial setup  
- Scheduled (typically daily)  
- On demand  
- Before processing orders when needed
