---
title: "Get menu from HAAT"
description: "Partner reads the HAAT menu for a business (categories, meals, deals, allocations)."
api: "GET http://ext-integration.haat-delivery.io/api/pos/business/{businessId}/menu"
---

Read-only. Returns the restaurant menu HAAT stores for this business. The **partner calls HAAT** with `X-Api-Key`.

Auth is Advanced API (`X-Api-Key`). For the reverse direction (HAAT calls your POS), use [Get menu from POS](/kits/restaurant/get-menu).

Does **not** return a `requestId` and does not create a sync audit entry. There is no `Pending` state.

Classification uses **Allocation** (`allocationId` / `allocations`). Do not expect `mealCategoryId` or `mealCategoryNames`.

JSON is camelCase. Localized names keep `en-US`, `ar`, `he`, `fr`. Allocation `name` is a single string, not a language dictionary.

**Example:**

### Meal content fields

Each `mealContents` item includes `haatId`, localized `name`, `price`, `available`, `imageUrl`, `allocationId` (nullable), plus:

| Field | Meaning |
| --- | --- |
| `isDefault` | Stored default-selected flag |
| `nonModifiable` | Stored non-modifiable flag |
| `maxCount` | Stored max amount, or `0` when null |

### Response rules

- **HAAT ids only.** Never POS ids, placement ids, or group-item ids.
- A meal content `haatId` is the ingredient menu-item id.
- Groups and deal groups have `haatId`, `name`, `min`, `max`, and children. They do **not** have `price`, `available`, or `imageUrl`.
- Meals, deals, and meal contents have `price`, `available`, and `imageUrl`.
- A deal meal's `price` is the deal-component price, or `0` when that price is null.
- A nested deal add-on uses the deal override price when one is stored.
- Group `min` / `max` are the stored values. Do not subtract fixed items and do not cap them.
- Hidden and deleted rows are omitted from category lists. Unavailable rows stay, with `available: false`.
- A hidden meal that is a visible choice inside a deal still appears inside that deal. Category meals stay hidden when Hide is set.
- Names keep every stored language. If `en-US` is missing or blank, fill it from `he`, then `ar`, then `fr`, then any other non-empty value.
- `imageUrl` prefers the small image, then the original. Prefix a relative path with the image host. Leave an absolute URL unchanged. Use `null` when there is no path or no host.
- Meal / deal `available` is `true` when `NotAvailable` is false or its unavailability expiration has passed, **and** the weekly hours say it is open now. Empty weekly hours means open. Uses the business country timezone; if the business has no country, Israel is used.
- Meal content `available` uses `NotAvailable` and the expiration date only (no weekly hours).
- Smart availability is **not** applied.
- This GET does **not** use the partner item ids from [Update availability](/kits/advanced-api/availability). That PUT still writes by those partner ids.
