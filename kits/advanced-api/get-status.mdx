---
title: "Get business status"
description: "Read whether a business is Open or Closed for POS display."
api: "GET http://ext-integration.haat-delivery.io/api/pos/business/{businessId}/status"
---

Read-only. Returns the partner display status mapped for POS.

This is **not** the same as [Update business status](/kits/advanced-api/update-status) (`PUT`), which writes Closed (`0`) / Open (`1`) and returns a sync `requestId`.

Auth uses the same `X-Api-Key`. Missing business returns `404`.

**Example:**

### Display mapping

| HAAT internal | Returned to POS |
| --- | --- |
| Open | `Open` |
| Busy | `Closed` |
| Close | `Closed` |
| Soon | `Closed` |

## Responses

<AccordionGroup>
  <Accordion title="200 — Current display status">
    Body is `{ "status": "Open" }` or `{ "status": "Closed" }`.
  </Accordion>
  <Accordion title="401 / 403 — Auth failed">
    Missing or invalid `X-Api-Key`.
  </Accordion>
  <Accordion title="404 — Business not found">
    Unknown `businessId` for this API key.
  </Accordion>
</AccordionGroup>
