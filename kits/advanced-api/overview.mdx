# Advanced API overview

Use this kit when the partner POS **calls HAAT** (not the other way around).

Each endpoint page in the sidebar shows **headers, body fields, and example responses** on the right.

Typical uses:

- Open / close a business
- Update order status (start prepare / cancel)
- Update working hours
- Update item availability
- Poll a request that returned `Pending`

## Advanced API environments

| Environment | Base URL |
| --- | --- |
| Staging | `http://ext-integration.haat-delivery.io` |
| Production | `https://integration.internal.haat.delivery` |

## How to read an endpoint

1. Open the page in the left menu.
2. Read `X-Api-Key` and the path fields in the middle.
3. Use the sample request and `200` / `400` responses on the right.
