---
title: "Update business status"
description: "Open or close a business."
api: "PUT http://ext-integration.haat-delivery.io/api/pos/business/{businessId}/status"
---

`status` `0` = Online (open). `status` `1` = Offline (closed). When closing, `closeExpirationDate` is required.

**Example:**

## Responses

<AccordionGroup>
  <Accordion title="200 — Success or queued">
    If `status` is `Pending`, poll Get request status.
  </Accordion>
  <Accordion title="400 — Validation failed">
    Closing without `closeExpirationDate` fails.
  </Accordion>
</AccordionGroup>

<RequestExample>
```bash cURL
curl -X PUT http://ext-integration.haat-delivery.io/api/pos/business/1021/status \
  -H "X-Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"status":0}'
```
</RequestExample>
