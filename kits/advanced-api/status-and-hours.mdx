# Status and hours

## Get prepare time

`GET /api/pos/business/{businessId}/prepare-time`

Optional query: `orderId`

Example response: `[10, 15, 20, 25, 30, 45, 60]`

## Get business status

`GET /api/pos/business/{businessId}/status`

Response: `{ "status": "Open" | "Closed" }` (display mapping for POS).

## Update business status

`PUT /api/pos/business/{businessId}/status`

| status | Meaning |
| --- | --- |
| `0` | Closed |
| `1` | Open |

Open:

```json
{ "status": 1 }
```

Close (optional expiration; HAAT may derive next opening time if omitted):

```json
{
  "status": 0,
  "closeExpirationDate": "2026-12-31T08:00:00Z"
}
```

## Get order status

`GET /api/pos/business/{businessId}/order-status?orderId={id}`

Response: `{ "orderId", "status": "New" | "Preparing" | "Ready" | "Done" | "Cancelled" }`

## Update order status

`PUT /api/pos/business/{businessId}/order-status`

| status | Meaning | Extra |
| --- | --- | --- |
| `1` | Start prepare | `estimationMinutes` required (> 0) |
| `2` | Cancel | |
| `3` | Done prepare | No `estimationMinutes`; requires prior Start prepare |

```json
{
  "orderId": 98765,
  "status": 1,
  "estimationMinutes": 20
}
```

```json
{
  "orderId": 98765,
  "status": 3
}
```

## Get working hours

`GET /api/pos/business/{businessId}/working-hours`

Response: `{ "days": [ ... ] }` — active open days only; closed days omitted. Empty `{ "days": [] }` when fully closed.

## Update working hours

`PUT /api/pos/business/{businessId}/working-hours`

Full replacement. Days not listed are closed.

- `day`: `1` Sunday … `7` Saturday  
- `type`: `0` specific hours (default), `1` Closed (do not send — omit the day), `2` open 24 hours  
- Times: `"HH:mm"` UTC  

```json
{
  "days": [
    {
      "day": 1,
      "hours": [
        { "fromHour": "08:00", "toHour": "14:00" },
        { "fromHour": "17:00", "toHour": "23:00" }
      ]
    },
    { "day": 6, "type": 2 }
  ]
}
```
