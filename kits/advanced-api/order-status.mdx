---
title: "Update order status"
description: "Start prepare, done prepare, or cancel an order."
api: "PUT http://ext-integration.haat-delivery.io/api/pos/business/{businessId}/order-status"
---

`status` `1` = Start Prepare. `status` `2` = Cancel. `status` `3` = Done Prepare.

Auth uses `X-Api-Key`. Missing or invalid key returns `401` / `403`.

Write responses use `Success`, `Pending`, or `Failed`. If `Pending`, poll [Get request status](/kits/advanced-api/request-status).

### Status values

| `status` | Meaning | Body |
| --- | --- | --- |
| `1` | Start Prepare | `{ "orderId", "status": 1, "estimationMinutes" }` |
| `2` | Cancel | `{ "orderId", "status": 2 }` |
| `3` | Done Prepare | `{ "orderId", "status": 3 }` — no `estimationMinutes` |

### Done Prepare (`status` `3`)

- Requires a prior successful **Start Prepare**
- Body is only `orderId` + `status: 3`
- Fails if the order is cancelled, already Done Prepare, or not started
- Can also fail when the order is pending customer approval, picker-restricted, or otherwise ineligible
- Failure returns HTTP `400` with response `status` `Failed` and a `message`

## Responses

<AccordionGroup>
  <Accordion title="200 — Success or queued">
    On success, `message` is like `Order {orderId} updated to {Status} successfully`. If response `status` is `Pending`, poll Get request status.
  </Accordion>
  <Accordion title="400 — Failed">
    Common cases: invalid `orderId` or `status`; order not found or wrong business; Start Prepare without `estimationMinutes`; Cancel / Done Prepare rule violations (not started, already done, cancelled, pending customer approval, picker-restricted, ineligible). Body has `status` `Failed` and `message`.
  </Accordion>
  <Accordion title="401 / 403 — Auth failed">
    Missing or invalid `X-Api-Key`.
  </Accordion>
</AccordionGroup>

<RequestExample>
```bash cURL Start Prepare
curl -X PUT http://ext-integration.haat-delivery.io/api/pos/business/1021/order-status \
  -H "X-Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"orderId":98765,"status":1,"estimationMinutes":20}'
```
