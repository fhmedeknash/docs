---
title: "Update working hours"
description: "Replace the weekly working hours for a business."
api: "PUT http://ext-integration.haat-delivery.io/api/pos/business/{businessId}/working-hours"
---

Full replacement. Any day you leave out is treated as closed. `day`: 1 = Sunday … 7 = Saturday.

**Example:**

<pre class="redoc-example"><code>X-Api-Key: YOUR_API_KEY</code></pre>

<div class="redoc-schema-label">REQUEST BODY SCHEMA: <strong>application/json</strong></div>

<div class="redoc-tree">
  <div class="redoc-field">
    <div class="redoc-field-name"><code>days</code><span class="redoc-required">required</span></div>
    <div class="redoc-field-meta"><div class="redoc-type">object[]</div><p>Each day has <code>day</code>, optional <code>type</code> (<code>0</code> scheduled, <code>2</code> 24 hours), and <code>hours</code> as <code>fromHour</code>/<code>toHour</code> in UTC.</p></div>
  </div>
</div>

## Responses

<details class="redoc-response" open>
  <summary><span class="redoc-code">200</span> Success or queued</summary>
  <div class="redoc-response-body">If <code>status</code> is <code>Pending</code>, poll Get request status.</div>
</details>

<details class="redoc-response redoc-response-error">
  <summary><span class="redoc-code">400</span> Validation failed</summary>
  <div class="redoc-response-body">Overlapping hours or a bad <code>day</code> value.</div>
</details>

<RequestExample>
```bash cURL
curl -X PUT http://ext-integration.haat-delivery.io/api/pos/business/1021/working-hours \
  -H "X-Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"days":[{"day":1,"hours":[{"fromHour":"08:00","toHour":"14:00"}]}]}'
```
</RequestExample>

<ResponseExample>
```json 200
{"requestId":"6651a3f2e1b2c3d4e5f60001","status":"Success","message":"Updated successfully"}
```
</ResponseExample>
