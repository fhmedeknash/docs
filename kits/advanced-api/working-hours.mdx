---
title: "Update working hours"
description: "Replace the weekly working hours for a business."
api: "PUT http://ext-integration.haat-delivery.io/api/pos/business/{businessId}/working-hours"
---

Full replacement. Any day you leave out is treated as closed. `day`: 1 = Sunday … 7 = Saturday.

**Example:**

<pre class="redoc-example"><code>X-Api-Key: YOUR_API_KEY</code></pre>

## Responses

  <summary><span class="redoc-code">200</span> Success or queued</summary>

<details class="redoc-response redoc-response-error">

</details>

<RequestExample>
```bash cURL
curl -X PUT http://ext-integration.haat-delivery.io/api/pos/business/1021/working-hours \
  -H "X-Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"days":[{"day":1,"hours":[{"fromHour":"08:00","toHour":"14:00"}]}]}'
```
</RequestExample>

{"requestId":"6651a3f2e1b2c3d4e5f60001","status":"Success","message":"Updated successfully"}
