---
title: "Update working hours"
description: "Replace the weekly working hours for a business."
api: "PUT http://ext-integration.haat-delivery.io/api/pos/business/{businessId}/working-hours"
---

Full replacement. Any day you leave out is treated as closed. `day`: 1 = Sunday … 7 = Saturday. Times are `HH:mm` UTC.

To read the schedule after an update, call [Get working hours](/kits/advanced-api/get-working-hours). GET uses the same `days` / `day` / `hours` / `type` / `fromHour` / `toHour` shape and the same UTC `HH:mm` convention. GET does not return a `requestId`.

**Example:**

### `type` values

| `type` | Meaning on PUT |
| --- | --- |
| `0` | Open with specific hours (`hours` required, one or more non-overlapping UTC ranges). **Default if `type` is omitted.** |
| `1` | Closed — **do not send**. Omit the day from `days` instead. |
| `2` | Open 24 hours (`hours` empty / not required) |

## Responses

<AccordionGroup>
  <Accordion title="200 — Success or queued">
    If `status` is `Pending`, poll Get request status.
  </Accordion>
  <Accordion title="400 — Validation failed">
    Overlapping hours or a bad `day` value.
  </Accordion>

<RequestExample>
```bash cURL
curl -X PUT http://ext-integration.haat-delivery.io/api/pos/business/1021/working-hours \
  -H "X-Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"days":[{"day":1,"hours":[{"fromHour":"08:00","toHour":"14:00"}]}]}'
```
</RequestExample>
