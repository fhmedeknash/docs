---
title: "Get order status"
description: "Read the current display status of an order."
api: "GET http://ext-integration.haat-delivery.io/api/pos/business/{businessId}/order-status"
---

Read-only. Returns the current order status string. Does **not** return a `requestId` and does not create a sync audit entry.

This is different from [Update order status](/kits/advanced-api/order-status) (`PUT`), which uses numeric `status` `1` / `2` / `3`. The GET string can change over time without another PUT.

## Responses

<AccordionGroup>
  <Accordion title="200 — Current order status">
    Body is `{ "orderId", "status" }` with a display string.
  </Accordion>
  <Accordion title="401 / 403 — Auth failed">
    Missing or invalid `X-Api-Key`.
  </Accordion>
  <Accordion title="404 — Not found">
    Unknown `orderId` or order not on this business.
  </Accordion>
</AccordionGroup>
