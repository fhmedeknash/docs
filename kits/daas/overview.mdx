# DaaS overview

Use this kit for **Delivery-as-a-Service** partners who submit delivery orders into HAAT.

## Flow

```mermaid
sequenceDiagram
  participant Partner
  participant HAAT
  Partner->>HAAT: Login
  HAAT-->>Partner: Bearer token
  Partner->>HAAT: List businesses
  Partner->>HAAT: Validate order
  Partner->>HAAT: Submit order
  Partner->>HAAT: Get status / Cancel
```
