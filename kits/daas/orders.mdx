# DaaS orders

Base path: `/api/daas`

**Auth for all endpoints on this page:** DaaS org JWT (`Authorization: Bearer <token>`)

## Validate then submit

1. `POST /api/daas/validate-order` — dry-run; returns pickup/delivery estimates; **does not create** an order  
2. `POST /api/daas/submit-order` — creates the order  

Both use the same body: `SubmitDaaSOrderRequest` (tables below).

---

## Validate order

`POST /api/daas/validate-order`

Same body as submit (§ Submit order). Dry-run only.

## Submit order

`POST /api/daas/submit-order`

### Body — `SubmitDaaSOrderRequest`

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| businessId | int | required unless `posBusinessId` is set | Haat business id |
| posBusinessId | string? | optional | If set, overrides `businessId` |
| daaSOrderId | string | required in practice | Partner order id |
| userDetails | object | required | See `userDetails` table |
| orderDetails | object | required for cash | See `orderDetails` table |
| estimatedPickupTime | DateTime | required | Israel local time, converted to UTC |
| bags | short | optional | Ignored if org `BagsInputRequired`; `<= 0` = no bags |
| isCashOrder | bool? | optional | `true` only if org cash is enabled |
| customerNotes | string? | optional | Else uses `userDetails.address.notes` |
| totalAmount | decimal? | optional | Cash: order price if set |
| deliveryFee | decimal? | optional | Cash: added on top of total |
| language | string? | optional | Default Hebrew (`he`) |

### `userDetails` — `SubmitDaaSOrderUserDetails`

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| name | string | required when creating a new user | Customer name |
| phoneNumber | string | required on submit | Lookup/create user; SMS |
| location | object | required | See `userDetails.location` |
| address | object | required | See `userDetails.address` (fields may be empty) |

### `userDetails.location` — `SubmitDaaSOrderUserDetailsLocation`

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| latitude | double | required | `0,0` = location not shared yet |
| longitude | double | required | `0,0` = location not shared yet |

### `userDetails.address` — `SubmitDaaSOrderUserDetailsAddress`

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| city | string | optional | |
| street | string | optional | |
| buildingNumber | string | optional | |
| notes | string | optional | Fallback customer notes |

### `orderDetails` — `SubmitDaaSCourierOrderDetails`

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| items | array of objects | required for cash pricing | See `orderDetails.items[]` |

### `orderDetails.items[]` — `SubmitDaaSCourierOrderItem`

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| id | int | optional | Line item id (default `0`) |
| name | string | optional | Item name |
| quantity | int | required for cash pricing | Count |
| price | decimal | required for cash pricing | Unit price |

## Cancel order

### Path

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| orderId | int | required | Haat order id |
