# DaaS setup

Base path: `/api/daas`

## Environments

| Environment | Base URL |
| --- | --- |
| Staging | `http://ext-integration.haat-delivery.io` |
| Production | `https://integration.internal.haat.delivery` |

Use staging credentials first. Production only after HAAT Integration sign-off.

## Credentials

| You get | Used for |
| --- | --- |
| Username / password | **Login** — then use the returned token |
| Bearer token | All other DaaS calls: `Authorization: Bearer <token>` |

Open **Login** in the left menu for the request body and the sample `200` response.

After login, open **List businesses** to get `businessId` values for orders (unless you use `posBusinessId` mapping).
