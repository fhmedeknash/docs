# DaaS setup

Base path: `/api/daas`

HAAT provides staging and production DaaS base URLs during onboarding.

## 1. Login

`POST /api/daas/authentication/login`

**Auth:** none

**Body:** `LoginUserDto`

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| username | string | required | Org DaaS username |
| password | string | required | Password (BCrypt) |

```json
{
  "username": "username",
  "password": "••••••••"
}
```

Use the returned token on all other partner calls:

```http
Authorization: Bearer <token>
```

## 2. Register business (admin)

`POST /api/daas/register/business`

**Auth:** admin JWT

**Body:** `RegisterBusinessToDaaSRequest`

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| businessId | int | required | Haat business to link |
| daaSOrganizationId | int | required | Target DaaS org |

<Info>
  Admin-only. Partners do not call this during day-to-day order flow.
</Info>

## 3. Register organization (admin)

`POST /api/daas/register/organization`

**Auth:** admin JWT

**Body:** `RegisterDaaSOrganizationRequest`

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| userName | string | required | Unique; stored lowercase |
| password | string | required | Hashed with BCrypt |

<Info>
  Admin-only. Used when onboarding a new DaaS organization.
</Info>

## 4. List businesses

`GET /api/daas/businesses`

**Auth:** DaaS org JWT

No params.

Returns businesses linked to the authenticated organization. Use `businessId` on order and update-business calls (unless you use `posBusinessId` mapping).
