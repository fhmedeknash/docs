# DaaS setup

Base path: `/api/daas`

HAAT provides staging and production DaaS base URLs during onboarding.

## 1. Login

`POST /api/daas/authentication/login`

**Auth:** none

**Body:** `LoginUserDto`

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| username | string | required | Org DaaS username |
| password | string | required | Password (BCrypt) |

```json
{
  "username": "username",
  "password": "••••••••"
}
```

Use the returned token on all other partner calls:

```http
Authorization: Bearer <token>
```

## 2. List businesses

`GET /api/daas/businesses`

**Auth:** DaaS org JWT

No params.

Returns businesses linked to the authenticated organization. Use `businessId` on order and update-business calls (unless you use `posBusinessId` mapping).
