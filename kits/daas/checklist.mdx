# DaaS checklist

- [ ] Staging credentials received
- [ ] Login returns a usable token
- [ ] Businesses list matches expected branches
- [ ] Validate order works
- [ ] Submit order returns `haatOrderId`
- [ ] Cash orders include item prices
- [ ] Status endpoint tested
- [ ] Cancel rules understood / tested
- [ ] Staging certification approved
- [ ] Production credentials issued
