# DaaS checklist

- [ ] Staging credentials received
- [ ] `POST /api/daas/authentication/login` returns a usable token
- [ ] `GET /api/daas/businesses` matches expected branches
- [ ] Update business tested (if partner uses it)
- [ ] `POST /api/daas/validate-order` returns estimates (no order created)
- [ ] `POST /api/daas/submit-order` returns `haatOrderId`
- [ ] Cash orders include item `quantity` / `price` when `isCashOrder` is true
- [ ] `GET /api/daas/orders/{orderId}/status` tested
- [ ] Cancel rules understood / tested
- [ ] Staging certification approved
- [ ] Production credentials issued
