---
title: "Submit order"
description: "Create a delivery order in HAAT."
api: "POST https://external-partners.example.haat.delivery/api/daas/submit-order"
---

`businessId` is required unless `posBusinessId` is set. When `isCashOrder` is `true`, item quantity and price are required.

## Responses

<details class="redoc-response" open>
  <summary><span class="redoc-code">200</span> Order submitted</summary>
  <div class="redoc-response-body">Returns <code>data.haatOrderId</code> for status and cancel.</div>
</details>

<RequestExample>
```bash cURL
curl -X POST https://external-partners.example.haat.delivery/api/daas/submit-order \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"businessId":180,"daaSOrderId":"DAAS-987654321","userDetails":{"name":"John Doe","phoneNumber":"+972544774783","location":{"latitude":32.522,"longitude":35.148},"address":{"city":"Umm El Fahem"}},"estimatedPickupTime":"2025-09-09T23:45:00"}'
```
</RequestExample>

</ResponseExample>
