# Market overview

Use this kit for **Market** partners (barcodes, weighable items, promotions).

## Who does what

| Direction | Who hosts | Purpose |
| --- | --- | --- |
| External API | Partner POS | HAAT reads menu & promotions, submits orders |
| HAAT API | HAAT | Partner syncs price & availability |

## HAAT API environments

The following API is already available from HAAT and can be used by the POS for authentication and product synchronization.

| Environment | Base URL |
| --- | --- |
| Staging | `http://ext-integration.haat-delivery.io` |
| Production | `https://integration.internal.haat.delivery` |
