---
title: "Get promotions"
description: "Return current and upcoming market promotions."
api: "GET https://pos.example.com/api/promotions"
---

HAAT calls **your** POS.

**Example:**

<pre class="redoc-example"><code>integrator-token: YOUR_INTEGRATOR_TOKEN
organization-token: YOUR_ORGANIZATION_TOKEN</code></pre>

## Responses

<details class="redoc-response" open>
  <summary><span class="redoc-code">200</span> List of promotions</summary>
  <div class="redoc-response-body">Include current and upcoming promotions.</div>
</details>

<details class="redoc-response redoc-response-error">
  <summary><span class="redoc-code">401</span> Missing or invalid tokens</summary>
  <div class="redoc-response-body">Reject the request if either token is missing or wrong.</div>
</details>

<RequestExample>
```bash cURL
curl https://pos.example.com/api/promotions \
  -H "integrator-token: YOUR_INTEGRATOR_TOKEN" \
  -H "organization-token: YOUR_ORGANIZATION_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[{"Code":1001,"Name":"3 Cola for 10","IsActive":1,"Qty":3,"Price":10,"Products":"1322666"}]
```
</ResponseExample>
