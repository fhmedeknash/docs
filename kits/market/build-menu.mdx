---
title: "Build menu"
description: "Return the full market catalog so HAAT can build the store menu."
api: "GET https://pos.example.com/api/menu/build"
---

HAAT calls **your** POS. Unit values: `1` = Countable, `2` = Weighable KG, `3` = Weighable Quantity.

**Rate Limiting:** If you send too many requests in a short time, you will receive a <span class="status-429">429 Too Many Requests</span> response.

**Example:**

<pre class="redoc-example"><code>integrator-token: YOUR_INTEGRATOR_TOKEN
organization-token: YOUR_ORGANIZATION_TOKEN</code></pre>
