# How we edit these docs

This site is owned by **Integration**. You do not need Git, OpenAPI, or R&D to update partner guides.

## Day-to-day editing

<Steps>
  <Step title="Open the Web Editor">
    Go to [app.mintlify.com/editor](https://app.mintlify.com/editor) and sign in with your HAAT Mintlify account.
  </Step>
  <Step title="Pick a page">
    Use the left sidebar. Partner content lives under **Market**, **Restaurant**, **HAAT API**, and **DaaS**.
  </Step>
  <Step title="Edit the text">
    Change wording, examples, checklists, or credentials notes. Keep one topic per page.
  </Step>
  <Step title="Publish">
    Click **Publish**. The live site updates at [haat.mintlify.app](https://haat.mintlify.app).
  </Step>
</Steps>

## What to edit vs leave alone

| Edit freely (Integration) | Ask R&D first |
| --- | --- |
| Guides, checklists, partner wording | Breaking API field changes |
| Examples and cURL samples | New endpoints / removed endpoints |
| Setup / credential instructions | Auth scheme changes |
| Go-live checklist items | Production base URL changes (confirm with ops) |

## Page rules (keep it easy)

- One page = one job (setup, menu, order, checklist)
- Prefer short Steps, Tips, and tables
- Put copy-paste JSON/cURL on every action page
- Do not duplicate the same field table on many pages — link to the action page instead

## Invite teammates

1. Mintlify dashboard → **Settings** → **Users**
2. Invite Integration colleagues by email
3. They edit in the Web Editor only — no Git required
